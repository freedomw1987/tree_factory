M01「聽」互動原型

點哪裡試什麼：右側控制台可切任一種狀態。
主流程：首頁 → 開始會議 → 會議中（逐字稿長出來）→ 長按結束。
重點試：①會議中切「網路中斷」看黃橫幅 ②切「鎖屏」看紅燈熄滅 + 誠實文案 ③長按「結束會議」直到填滿（防誤觸）④點「發言者 3」→ 它會說「會議中維持編號，會後再命名」
逐字稿跟隨（決策 D2）：切到「上滑看歷史（停止跟隨）」再用下面的按鈕模擬新句子進來 → 右下角「回到最新 · N 句新」會累加；點它才回到最新。

2 小時上限（決策 D5）：切「剩 5 分鐘（接近上限）」看黃橫幅；切「已達 2 小時上限」看紅燈熄滅 + 「接下來的內容不會被記錄」+ 產生記錄 / 開新一場。按鈕可跳到 M02「記錄產生中」。
