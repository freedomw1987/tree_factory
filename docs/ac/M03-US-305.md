# M03-US-305 AC 範本

> 對應 Backlog: [M03-US-305 in docs/backlog.md](../backlog.md)
> Module: M03（問：對話為入口、跨會議檢索與問答）
> 最後更新: 2026-10-07

## 背景

作為使用者，我想在被誤導之前被告知「記錄裡沒有這件事」，以便我不會把 agent 的推測當成會議事實。

**這是本產品最重要的一條負向 AC。** 會議記錄 agent 一旦開始編造，整份記錄的可信度就歸零，
而且使用者通常無法察覺（因為編造的内容語句通順、人名也對）。

AC-4 要求以**已知無答案**的問題集做負向探針，目標是編造率 0。

## Given / When / Then

- **Given** 檢索結果無任何相關內容
  **When** agent 產生回答
  **Then** 明確說「記錄中沒有提到這個」，並說明搜尋範圍
  **And** 不得以常識或推測補足內容

- **Given** 查無資料
  **When** 顯示回答
  **Then** 附上「可能相關的會議」清單（依時間或關鍵字近似），每項可點

- **Given** 問題與會議記錄無關（例：「明天天氣如何」）
  **When** agent 回答
  **Then** 明說「這超出會議記錄的範圍」，不得作答

- **Given** 一組事先確認「記錄中確實沒有答案」的問題
  **When** 對 agent 逐題提問
  **Then** 編造率必須為 0（每題都必須是「查無」或「超出範圍」）

## DoD（Definition of Done）

- [ ] 負向探針題組（≥20 題）建檔，且每題的「正確答案是查無」有依據
- [ ] 斷言以「是否出現未在逐字稿中的實體（人名/數字/日期）」為機械判準，不靠肉眼
- [ ] 查無回答不得觸發 M03-US-302 的來源標示（沒有來源就不標）
- [ ] 探針 `REGRESSION_MODULE=M03` 全綠
