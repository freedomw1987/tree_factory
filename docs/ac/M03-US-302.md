# M03-US-302 AC 範本

> 對應 Backlog: [M03-US-302 in docs/backlog.md](../backlog.md)
> Module: M03（問：對話為入口、跨會議檢索與問答）
> 最後更新: 2026-10-07

## 背景

作為使用者，我想知道 agent 的答案**是從哪句話來的**，以便我能驗證它沒有亂講。

這是本產品與「一般 chatbot」的分野：**沒有來源的答案對會議記錄沒有價值**。
本 US 的 AC-4 是負向探針——來源必須可解析回真實存在的句子，不得引用幻覺的 `source_seq`。

## Given / When / Then

- **Given** agent 產生了一段實質回答（非「查無資料」類）
  **When** 回答顯示完成
  **Then** 每條結論至少附 1 個來源，格式含「會議名稱 + 時間 + 發言者」

- **Given** 使用者看到一條來源
  **When** 點擊它
  **Then** 跳至該場會議的逐字稿、自動捲到該句並高亮；使用者可按返回回到對話

- **Given** 被引用的句子曾被人工編輯過（決策 D7/D8）
  **When** 該來源顯示
  **Then** 標示「此句有人工修正」，讓使用者知道這不是機器原始輸出

- **Given** agent 產出的 `source_seq` 清單
  **When** 對照該場逐字稿
  **Then** 每一個 `source_seq` 都必須能解析到真實存在的句子
  **And** 若解析失敗，該條回答必須降級為「查無資料」而非照樣輸出

## DoD（Definition of Done）

- [ ] 來源契約（`source_seq` → 句子）有單元測試，含「不存在的 seq 必須被拒絕」
- [ ] 負向探針：餵入含假 `source_seq` 的模型輸出，斷言系統不輸出該答案
- [ ] 點來源回溯的捲動與高亮在原型中實測（非肉眼）
- [ ] 人工修正標示的資料來源為 `edited_at` 而非猜測
- [ ] 探針 `REGRESSION_MODULE=M03` 全綠
