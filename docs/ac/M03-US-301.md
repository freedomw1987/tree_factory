## 背景

作為會議記錄的使用者，我想一打開 app 就能直接問問題，以便我不需要先找到是哪一場會議。

**首頁 IA 反轉（決策 D9）**：v1 起首頁**不再是會議列表**，而是對話框。會議列表降級為「會議」分頁。
理由：使用者的真實起點是「我記得有講過但忘了在哪一場」——先找會議是舊工具的思考方式。

本 US 是 M03 的入口票。AC-3 特別重要：**沒有任何會議記錄時必須明說**，
不得讓使用者以為 agent 什麼都能答。

## Given / When / Then

- **Given** 使用者開啟 app（且至少已有一場會議記錄）
  **When** 首頁載入
  **Then** 直接顯示對話框（輸入框 + 對話串），可立即輸入；不需要先選會議

- **Given** 使用者已輸入問題
  **When** 送出
  **Then** 3 秒內先出現「正在查記錄…」的回饋，再逐字串流答案；期間輸入框 disabled

- **Given** 資料庫中沒有任何會議記錄
  **When** 使用者開啟 app
  **Then** 明說「還沒有任何會議記錄，我沒有東西可以查」，並提供「開始一場會議」引導 CTA
  **And** 不得顯示空白的對話框假裝可用、不得編造答案

- **Given** 答案正在串流中
  **When** 使用者檢視畫面
  **Then** 已產出的部分逐字長出（不是整段一次跳出），且捲動自動跟隨最新內容
