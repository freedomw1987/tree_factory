# M03-US-307 AC 範本

> 對應 Backlog: [M03-US-307 in docs/backlog.md](../backlog.md)
> Module: M03（問：對話為入口、跨會議檢索與問答）
> 最後更新: 2026-10-07

## 背景

作為正在看某一場會議的使用者，我想直接問「這場會議」的問題，以便我不需要重新描述上下文。

本 US 是**範圍鎖定**的入口，對應 `INT-M02-M03-01`。
AC-2 是誠實條款：鎖定範圍後若問了跨場問題，必須明說目前只搜尋本場，而不是偷偷只搜本場後給出看似完整的答案。

## Given / When / Then

- **Given** 使用者正在會議詳情頁
  **When** 點「問這場」
  **Then** 開啟對話框且範圍鎖定為本場會議，UI 明確顯示「搜尋範圍：本場會議」

- **Given** 對話範圍已鎖定為本場
  **When** 使用者問了一個明顯跨場的問題
  **Then** 明說「目前只搜尋本場」，並提供「改為搜尋全部會議」一鍵切換
  **And** 不得靜默只搜本場後回答

- **Given** 使用者從「本場」切換為「全部會議」
  **When** 範圍變更
  **Then** 原本的對話串保留，範圍指示隨之更新（不開新對話）

## DoD（Definition of Done）

- [ ] 範圍參數（`scope = meeting_id | all`）以參數傳入引擎，不靠 prompt 提示
- [ ] 範圍指示器有穩定測試（切換後文字必須改變）
- [ ] 切換範圍不重設對話串
- [ ] 探針 `REGRESSION_MODULE=M03` 全綠
