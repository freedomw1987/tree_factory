## 背景

作為會議參與者，我想把會議記錄匯出成 Markdown 或分享給其他 app，以便記錄能進入我原有的工作流（筆記軟體、訊息）。

v1 刻意只做匯出、不做自動推送到 Notion / Slack（見 backlog §5 Non-goals）：外部授權會把 v1 的範圍炸開。

## Given / When / Then

- **Given** 一份已產生的會議記錄
  **When** 使用者選擇匯出 Markdown
  **Then** 產出一個含三層結構（逐字稿 / 摘要 / 待辦）的檔案

- **Given** 匯出的 Markdown 檔案
  **When** 在外部工具（如 Obsidian）開啟
  **Then** 標題層級正確、待辦清單可渲染為 checkbox
  **And** 不得出現破損的表格或未閉合的程式碼區塊

- **Given** 使用者選擇分享
  **When** 使用系統分享面板
  **Then** 可傳送至其他 app
  **And** 接收端內容與本機匯出檔一致

## DoD（Definition of Done）

- [ ] 匯出檔的 frontmatter（日期 / 會議時長 / 參與者）欄位固定，並與 M04-US-401 的命名對應
- [ ] 匯出內容以實際在 Obsidian 開啟驗證（非只看檔案內容）
- [ ] 分享路徑以 iOS 系統分享面板實測，並記錄曾測過的目標 app
- [ ] `REGRESSION_MODULE=M04` 全綠
