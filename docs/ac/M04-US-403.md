## 背景

作為使用者，我想直接編輯摘要與待辦，以便修正 agent 的錯誤歸納。

**這與逐字稿編輯的性質不同**，依決策 D8 的分層原則：
- 逐字稿 = **事實層**（有人真的說過）→ 可改但留旗標
- 摘要 / 待辦 = **推論層**（agent 的歸納）→ 可直接改，不需要旗標，因為它本來就不是事實

AC-2 保留 M02 的鐵律：待辦期限不得由**模型**填入，但**人工**當然可以填。

## Given / When / Then

- **Given** 使用者正在檢視會議摘要或待辦
  **When** 點任一欄位（決策 / 爭點 / 結論 / 待辦的 who / what / due）
  **Then** 可直接編輯並儲存

- **Given** 使用者編輯待辦的「期限」
  **When** 儲存
  **Then** 人工填入的日期被接受；M02 的鐵律（**模型不得自行填入期限**）不受影響
  **And** 必須能區分「人工填的期限」與「模型抽取的期限」

- **Given** 摘要或待辦被人工編輯過
  **When** 重新產生記錄
  **Then** 明說「重新產生會覆蓋你的人工編輯」，需使用者確認後才執行
  **And** 不得靜默覆蓋使用者的修改

## DoD（Definition of Done）

- [ ] 摘要三區塊與待辦欄位皆可編輯並持久化
- [ ] `due` 需有來源標記（`source = human | model`），且模型來源不得為幻覺日期
- [ ] 重新產生前的覆蓋警告有探針（未確認不得覆蓋）
- [ ] 決策 D8 分層（事實層留旗標 / 推論層不留）已寫入 `DESIGN.md`
- [ ] 探針 `REGRESSION_MODULE=M04` 全綠
