# M01-US-105 AC 範本

> 對應 Backlog: [M01-US-105 in docs/backlog.md](../backlog.md)
> Module: M01（聽：收音與即時逐字稿）
> 最後更新: 2026-10-07（v1.1，決策 D1）

## 背景

作為會議參與者，我想在**會後**把「發言者 2」改成「阿明」，以便記錄能對應到真實的人，而不是編號。

工程成本極低但價值極高：沒有這一條，會議記錄對使用者幾乎不可用。本 US 也是 diarization 只有編號沒有名字這個事實（見 backlog §0.1）的直接補救。

**決策 D1（2026-10-07）**：命名**只在會後**做。會議中的逐字稿畫面刻意沒有任何可點的文字 ——
P1「會議中零打擾」優先於 P5「人比編號重要」。命名入口由 M02 的「逐字稿」分頁提供（FR-217），
本 US 負責資料層（編號 → 名字）的套用與 fallback 規則。

## Given / When / Then

- **Given** 會議已結束、逐字稿存在 3 位未命名的 speaker（顯示為「發言者 1/2/3」）
  **When** 使用者在「逐字稿」分頁點提示、於命名 sheet 一次輸入 3 個名字並套用
  **Then** 該場會議所有歷史句子同步換成名字
  **And** 待辦事項的負責人欄位也同步換成名字（同一份對應表，不得出現編號與名字並存）

- **Given** 逐字稿畫面已顯示歷史句子
  **When** 命名套用
  **Then** 已顯示的句子必須同步更新，不得只有新句子改變
  **And** 捲動位置不得跳動

- **Given** 命名 sheet 有欄位留空
  **When** 使用者按「一次套用」
  **Then** 有填名字的欄位生效，留空的維持「發言者 N」（部分套用合法）
  **And** 若三個欄位全空則擋下並說明原因，不得靜默套用

- **Given** 某 speaker 未被命名
  **When** 逐字稿或匯出檔案顯示該 speaker
  **Then** 顯示為「發言者 2」
  **And** 不得顯示為空白、`speaker_2` 或原生 0 起算的數字

## DoD（Definition of Done）

- [ ] 命名對應表以 speaker 編號為鍵持久化，且與 M01-US-103 的編號一致性假設對齊
- [ ] **會議中畫面沒有任何命名入口**（探針鎖定：會議中點發言者 chip 不開 sheet、不改資料）
- [ ] 命名採批次：一次顯示全部未命名者，套用一次生效（不得強迫逐位開關 sheet）
- [ ] 歷史句子與待辦負責人批次更新後，捲動位置不跳動
- [ ] 未命名 fallback 文字（「發言者 N」）以探針鎖定，防止顯示原生編號
- [ ] 名字長度上限 20 字元，超出截斷且畫面不破版
- [ ] `REGRESSION_MODULE=M01` 全綠
