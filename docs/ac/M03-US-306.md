## 背景

作為網路不穩的使用者，我想在答案中斷時能重試，以便我不必重新描述問題。

## Given / When / Then

- **Given** 答案正在串流
  **When** 網路中斷
  **Then** 顯示中斷提示與「重試」按鈕，且已串流出的內容保留並標示「未完成」

- **Given** 使用者按下「重試」
  **When** 重試進行
  **Then** 沿用同一個問題，**不得**在對話串中新增第二個使用者泡泡

- **Given** 重試期間
  **When** 使用者再次觸發送出
  **Then** 被擋下（同一問題不得並行兩次請求）

## DoD（Definition of Done）

- [ ] 重試使用同一 `idempotency_key`，伺服端據此去重（與 M02 同一原則）
- [ ] 部分內容保留 + 「未完成」標示有穩定測試
- [ ] 失敗不得導致對話歷史寫入半截資料
- [ ] 探針 `REGRESSION_MODULE=M03` 全綠
