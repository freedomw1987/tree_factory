# M03-US-303 AC 範本

> 對應 Backlog: [M03-US-303 in docs/backlog.md](../backlog.md)
> Module: M03（問：對話為入口、跨會議檢索與問答）
> 最後更新: 2026-10-07

## 背景

作為使用者，我想問跨越多場會議的問題，以便我掌握「這一季的走向」而不是單場細節。

與 `M02-US-205` 的邊界：**M02-US-205 是單場追問（scope 鎖定本場），M03 是跨場彙整**。
兩者共用 M03 的問答引擎，見 `INT-M02-M03-01`。

AC-4 是誠實條款：檢索必然有範圍上限，超過時必須明說，不得讓使用者以為「全部都在裡面」。

## Given / When / Then

- **Given** 已有多場會議記錄，且問題涉及跨場主題
  **When** 送出問題（例：「這季所有延後的決定」）
  **Then** 回答彙整多場記錄，**逐條**附上各自的來源（不得合併成無法回溯的一段敘述）

- **Given** 彙整結果包含多條
  **When** 顯示
  **Then** 依時間排序（新 → 舊），且每條明示來自哪一場會議

- **Given** 其中一場記錄為空或尚未產生三層記錄
  **When** 彙整
  **Then** 該場被跳過，且回答中明說「N 場尚未產生記錄，未納入」

- **Given** 符合條件的會議數超過檢索上限
  **When** 產生回答
  **Then** 明說「只搜尋了最近 N 場，可能還有更早的」，並提供「擴大範圍」選項
  **And** 不得靜默截斷後宣稱這是全部

## DoD（Definition of Done）

- [ ] 跨場彙整的每條結果都可回溯（與 M03-US-302 同一契約）
- [ ] 檢索上限為明確常數且有測試（不得寫死在 prompt 裡）
- [ ] 「尚未產生記錄的場次不納入且明說」有探針
- [ ] 排序穩定（同時間時有明確 tie-breaker，不得每次順序不同）
- [ ] 探針 `REGRESSION_MODULE=M03` 全綠
