# M04-US-406 AC 範本

> 對應 Backlog: [M04-US-406 in docs/backlog.md](../backlog.md)
> Module: M04（編：知識層與人工編輯）
> 最後更新: 2026-10-07

## 背景

作為使用者，我想用標籤把會議與概念分組，以便我按主題（專案、客戶、季度）查找與限定對話範圍。

P2 優先級：這是「累積到一定量」之後才需要的整理能力，且與 M03-US-303 的「擴大範圍」互補。

## Given / When / Then

- **Given** 一場會議或一個概念
  **When** 使用者加上標籤
  **Then** 標籤被保存，並顯示在該會議 / 概念上

- **Given** 已有多個標籤
  **When** 使用者以標籤篩選
  **Then** 會議列表與對話檢索範圍都可依標籤限縮
  **And** 目前生效的篩選條件必須一直可見（避免使用者以為看到的是全部）

- **Given** 系統建議了一個標籤（機器產生）
  **When** 顯示建議
  **Then** 必須與使用者自行建立的標籤有視覺區別，且需使用者確認才生效

## DoD（Definition of Done）

- [ ] 標籤來源（`human | suggested`）可區分
- [ ] 篩選條件生效時有持續可見的指示（不得變成隱形狀態）
- [ ] 刪除標籤不得刪除會議或概念（只解除關聯）
- [ ] 探針 `REGRESSION_MODULE=M04` 全綠
