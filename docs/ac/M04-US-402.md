# M04-US-402 AC 範本

> 對應 Backlog: [M04-US-402 in docs/backlog.md](../backlog.md)
> Module: M04（編：知識層與人工編輯）
> 最後更新: 2026-10-07

## 背景

作為使用者，我想在 agent 引用人工修改過的句子時被提醒，以便我能判斷這句話的可信度。

**決策 D8 的落地**。這條 US 存在的唯一理由是：決策 D7 放棄了原始文字，
若連「被改過」這個訊號都不留，記錄就完全無法分辨「當時真的這樣說」與「後來有人這樣寫」。

設計上刻意**不干擾使用者**：逐字稿畫面完全不顯示旗標，只在 agent 引用時提醒。

## Given / When / Then

- **Given** 使用者編輯了一句逐字稿
  **When** 該句儲存
  **Then** 系統記錄 `edited_at`（時間戳）
  **And** 逐字稿畫面**不**顯示任何「已編輯」標記（保持零負擔）

- **Given** 某句已被人工編輯
  **When** agent 的回答引用到該句
  **Then** 該條來源旁標示「此句有人工修正」

- **Given** 一句曾被編輯但後來被改回原樣
  **When** agent 引用它
  **Then** 仍標示「此句有人工修正」（因為無法證明已還原——決策 D7 不留舊版）
  **And** 此行為需在文件明說，不得讓使用者誤解為 bug

## DoD（Definition of Done）

- [ ] `edited_at` 欄位存在於 `transcript_segment`，且寫入時機有測試
- [ ] 逐字稿 UI **無**旗標顯示（反向斷言：DOM 不得含「已編輯」字樣）
- [ ] agent 引用時的標示有端到端探針（改一句 → 問到它 → 斷言標示出現）
- [ ] 「改回原樣仍標示」的行為已寫入 `system-design.md` 或 PRD，避免被當成 bug 修掉
- [ ] 探針 `REGRESSION_MODULE=M04` 全綠
