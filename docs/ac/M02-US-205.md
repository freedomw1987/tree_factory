# M02-US-205 AC 範本

> 對應 Backlog: [M02-US-205 in docs/backlog.md](../backlog.md)
> Module: M02（記：記錄與查詢）
> 最後更新: 2026-10-07

## 背景

作為會議參與者，我想在會後用講話的方式追問那場會議，以便我不用重讀整份逐字稿就能找到我要的答案。

會議中 AI 靜音的決策把 TTS 全部推到這裡，所以這是 v1 唯一保留「語音對話」體驗的位置。
技術上與會議模式不同：這裡可以使用 `withVoice`（含 TTS），因為沒有回音迴路的風險。

## 範圍（v2.0 變更）

本 US 原本包含檢索與回答邏輯（5 SP），v2.0 起**檢索 / 排序 / 附來源全部歸 M03 問答引擎**，
本票只保留「單場入口 + TTS 出聲 + barge-in」三件事，改為呼叫 M03 的 `ask()` 並傳 `scope = meeting_id`。
介面契約見 [INT-M02-M03-01.md](./INT-M02-M03-01.md)。**優先級由 P2 升為 P1**
（M03 落地後成本下降，且這是 v1 唯一能以語音提問的入口）。

## Given / When / Then

- **Given** 一場已結束的會議
  **When** 使用者開啟追問模式並問「剛剛誰負責預算？」
  **Then** 以語音（TTS）回答
  **And** 答案可回溯至逐字稿的具體句子

- **Given** 使用者提問的內容超出該場會議的範圍
  **When** 系統產生回答
  **Then** 明確回答「這場會議沒有提到」
  **And** 不得編造不在逐字稿中的資訊

- **Given** TTS 正在播放回答
  **When** 使用者開始說話
  **Then** 立即停止播放並切換為收音（barge-in）
  **And** 被打斷的回答內容不得被計入下一輪的上下文而重複

## DoD（Definition of Done）

- [ ] M02 端**不含**任何檢索 / 排序 / 去重邏輯（只有呼叫 M03 引擎與顯示）
- [ ] 呼叫時明確傳 `scope = meeting_id`，不靠 prompt 提示範圍
- [ ] 來源格式與 M03 首頁對話框一致（同一 renderer）；「此句有人工修正」標示由引擎提供

- [ ] 追問的檢索範圍嚴格限制在該場會議的逐字稿（session 邊界不得洩漏到其他會議）
- [ ] 「查無此資訊」以負向探針鎖定（問一個會議沒提過的問題，斷言答案為查無且不含具體數字 / 人名）
- [ ] barge-in 行為有測試，並確認中斷後的上下文乾淨
- [ ] TTS 輸出與會議模式（`withVoiceInput`）在此模組並存而不互相影響
- [ ] `REGRESSION_MODULE=M02` 全綠
