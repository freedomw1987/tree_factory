# M02-US-205 AC 範本

> 最後更新: 2026-10-07

## 背景

作為會議參與者，我想在會後用講話的方式追問那場會議，以便我不用重讀整份逐字稿就能找到我要的答案。

會議中 AI 靜音的決策把 TTS 全部推到這裡，所以這是 v1 唯一保留「語音對話」體驗的位置。
技術上與會議模式不同：這裡可以使用 `withVoice`（含 TTS），因為沒有回音迴路的風險。

## Given / When / Then

- **Given** 一場已結束的會議
  **When** 使用者開啟追問模式並問「剛剛誰負責預算？」
  **Then** 以語音（TTS）回答
  **And** 答案可回溯至逐字稿的具體句子

- **Given** 使用者提問的內容超出該場會議的範圍
  **When** 系統產生回答
  **Then** 明確回答「這場會議沒有提到」
  **And** 不得編造不在逐字稿中的資訊

- **Given** TTS 正在播放回答
  **When** 使用者開始說話
  **Then** 立即停止播放並切換為收音（barge-in）
  **And** 被打斷的回答內容不得被計入下一輪的上下文而重複

## DoD（Definition of Done）

- [ ] 追問的檢索範圍嚴格限制在該場會議的逐字稿（session 邊界不得洩漏到其他會議）
- [ ] 「查無此資訊」以負向探針鎖定（問一個會議沒提過的問題，斷言答案為查無且不含具體數字 / 人名）
- [ ] barge-in 行為有測試，並確認中斷後的上下文乾淨
- [ ] TTS 輸出與會議模式（`withVoiceInput`）在此模組並存而不互相影響
- [ ] `REGRESSION_MODULE=M02` 全綠
