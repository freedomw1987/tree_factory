# M03-US-308 AC 範本

> 對應 Backlog: [M03-US-308 in docs/backlog.md](../backlog.md)
> Module: M03（問：對話為入口、跨會議檢索與問答）
> 最後更新: 2026-10-07

## 背景

作為在手機上用對話框查記錄的使用者，我想直接用說的問問題，以便開車後、走路時也能查。

## Given / When / Then

- **Given** 對話框（首頁）
  **When** 使用者按下 mic 並說話後停止
  **Then** 辨識結果**填入輸入框**（不直接送出），使用者確認後才發出提問

- **Given** 語音辨識失敗或逾時
  **When** 失敗回報
  **Then** 明說「沒聽清楚，再說一次」並保留輸入框原有內容；**不得**送出半截句子
  （送出半截句子＝拿錯誤問題去問，會連帶得到錯誤答案）

- **Given** 麥克風權限尚未授權
  **When** 使用者按下 mic
  **Then** 顯示權限說明與引導（不得靜默失敗）；已授權者按下 mic 直接開始收音、不重複詢問

## DoD（Definition of Done）

- [ ] 「先填後送」是硬斷言：任何情況下辨識結果都不會自動送出（含完全符合既有問題的短句）
- [ ] 語音輸入**不啟用會議錄音的 diarize / 分段上傳路徑**（對話是單人、短句；重用 STT 服務但不重用會議收音管線）
- [ ] 會議錄音進行中時，對話框的 mic **不可用**（避免與會議收音搶麥克風，明說原因）
- [ ] 權限拒絕後仍可用打字提問（不得因權限問題鎖住整個對話框）
- [ ] 失敗路徑有穩定測試（辨識失敗 / 權限拒絕 / 會議中按 mic）
- [ ] 探針 `REGRESSION_MODULE=M03` 全綠
