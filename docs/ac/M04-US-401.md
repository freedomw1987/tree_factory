# M04-US-401 AC 範本

> 對應 Backlog: [M04-US-401 in docs/backlog.md](../backlog.md)
> Module: M04（編：知識層與人工編輯）
> 最後更新: 2026-10-07

## 背景

作為使用者，我想修正聽錯的逐字稿，以便記錄是對的。

**決策 D7（用戶拍板）**：逐字稿原句**可以直接改寫，不留舊版**。理由是收音品質導致的錯字是真實痛點，
而保留舊版對「修錯字」這個主要用途沒有幫助。

**決策 D8（Agent 建議並實作）**：只留一根 `edited_at` 旗標（不存舊文字），且**逐字稿 UI 不顯示**，
僅在 agent 引用時提醒「此句有人工修正」。

AC-2 界定可改與不可改：`text` 可改；`speaker_id` 與時間戳不可在此改（改名走 M01-US-105 的流程），
避免兩條路徑同時能改 speaker 造成資料不一致。

## Given / When / Then

- **Given** 使用者正在檢視逐字稿
  **When** 點任一句
  **Then** 進入編輯狀態（該句變為可輸入），可修改文字並儲存
  **And** 儲存後畫面立即更新，不需重載整場記錄

- **Given** 使用者正在編輯一句逐字稿
  **When** 檢視可修改的欄位
  **Then** 只有 `text` 可改；`speaker_id`（發言者）與時間戳**不可**在此修改
  **And** 改名一律走 M01-US-105 的會後命名流程（避免兩條路徑衝突）

- **Given** 使用者把該句清空或貼上超長內容（> 2,000 字元）
  **When** 嘗試儲存
  **Then** 擋下並說明原因（不得存入空白句或超長句）

- **Given** 某場會議的逐字稿已被人工編輯
  **When** 重新產生摘要與待辦
  **Then** 以**編輯後**的文字為輸入
  **And** 事先明說「重新產生會採用你修正後的內容」

## DoD（Definition of Done）

- [ ] 編輯寫入 `edited_at`（決策 D8），**不**建立版本表（決策 D7）
- [ ] 空白 / 超長 / 僅空白字元三種邊界有探針
- [ ] 編輯與 M01-US-105 命名是兩條不重疊的路徑（改名不得寫 `text`）
- [ ] 重新產生摘要使用編輯後內容，且有探針證明（改一句 → 摘要跟著變）
- [ ] 探針 `REGRESSION_MODULE=M04` 全綠
