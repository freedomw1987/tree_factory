## 背景

作為會議參與者，我想一鍵開始與結束會議錄音，以便我不需要思考技術細節就能把會議錄下來。

本 US 是 M01 的入口票，也是整個產品的第一個可驗證動作。AC-4 特別要求「被中斷時不得假裝仍在錄」，
因為一個騙人的錄音指示燈比沒有指示燈更糟——使用者會以為自己錄到了。

## Given / When / Then

- **Given** app 在前景且已取得麥克風權限
  **When** 使用者點「開始會議」
  **Then** 3 秒內進入「錄音中」狀態並顯示累計時間

- **Given** 正在錄音
  **When** 使用者點「結束會議」
  **Then** 立即停止收音並保留本次 session 於本機
  **And** 不得刪除任何已產生的逐字稿或音檔

- **Given** 尚未取得麥克風權限
  **When** 使用者首次點「開始會議」
  **Then** 顯示為何需要麥克風的說明，並提供前往系統設定的入口
  **And** 不得靜默失敗（不可只把按鈕變灰而無說明）

- **Given** 正在錄音
  **When** app 被切換到背景或裝置鎖屏
  **Then** 畫面明確顯示「錄音已中斷」狀態
  **And** 不得繼續顯示錄音中的計時器

## DoD（Definition of Done）

- [ ] 在 iOS 真機（非僅模擬器）驗證通過，模擬器無麥克風故不作為驗收依據
- [ ] `Info.plist` 的 `NSMicrophoneUsageDescription` 已填寫且文字為使用者可理解的說明
- [ ] 探針 `REGRESSION_MODULE=M01` 全綠
- [ ] 錄音狀態機（idle / recording / interrupted）有單元測試
- [ ] 已在 `docs/spike/SPIKE-002.md` 記錄真機實測結果作為佐證
